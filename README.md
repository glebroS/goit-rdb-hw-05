## **Опис проекту**

У цьому репозиторії представлено виконання практичного завдання з написання вкладених SQL-запитів та створення користувацьких функцій.

Головна мета: оптимізація обробки даних без використання стандартних операторів об'єднання (JOIN), застосовуючи підзапити на різних рівнях (SELECT, WHERE, FROM) та використання CTE (Common Table Expressions).

## **Вміст репозиторію**

* SQL Commands.txt — Файл із текстом усіх виконаних SQL-запитів та створеною функцією.  
* p1\_select\_nested.png — Результат використання вкладеного запиту в операторі SELECT для отримання customer\_id.  
* p2\_where\_nested.png — Результат фільтрації даних за допомогою вкладеного запиту в WHERE (shipper\_id=3).  
* p3\_from\_nested.png — Результат обчислення середньої кількості товару з використанням підзапиту в FROM.  
* p4\_with\_cte.png — Результат виконання аналогічного запиту з використанням тимчасової таблиці WITH.  
* p5\_custom\_function.png — Результат створення та застосування власної функції divide\_float до колонки quantity.

## **Інструменти**

* MySQL / MySQL Workbench  
* Вкладені SQL-запити (Nested Queries)  
* Оператор WITH (CTE)  
* Розробка функцій (CREATE FUNCTION, DELIMITER)
